# Dependencies for waveform-analysis.  See the Environment section in README.md.
#
# waveform-io supplies `hodoscope_common` (the file layout, the waveform primitives) and
# `file_manipulation` (the MIDAS parser and TTT clock recovery, which timing_stability
# calls directly).  It is NOT on PyPI -- install it first, one of two ways:
#
#   development, tracks your local edits:
#       pip install -e ../waveform-io
#
#   reproducible, pinned:
#       pip install "waveform-io @ git+https://github.com/remy-strichartz/waveform-io.git@v0.1.0"
#
#   waveform-io is public, so the git form needs no credentials.  If it is ever made
#   private again, switch to git+ssh:// -- pip cannot use the token `gh auth` keeps in
#   the keyring.
#
# The scipy floor is NOT optional: the MIP line is fit with scipy.stats.landau
# (mv_pipeline.py), which older scipy does not carry -- it fails at import rather than
# degrading gracefully, and the Landau (x) Gauss fit *is* the energy reconstruction.
scipy>=1.16
